# 今日歷歷 · Kontext Dashboard

> 一張打開即用的極簡個人作戰桌。時間的河流，就從今天開始。

---

## 🌿 設計理念

本專案以**日系手帳美學**為骨，以**極簡主義（Minimalism）**為肉，試圖將個人的每日工作節奏收納進一個安靜、剋制、卻足以讓人沉下心來的頁面。

靈感來自 Kontext.jp 的「留白即是設計、剋制即是力量」哲學——

- **少，但更好。** 不是功能越多越好，而是把最有用的功能做到極致精緻。
- **工具是為人服務的。** 儀表板應該安靜地等候，不打擾人，在需要的時候精準呈現。
- **日常即文學。** 一條時間軸、一個待辦清單，也可以有書頁的溫度。

## ✨ 目前功能一覽

### 📌 頁首（Header）

| 元素 | 說明 |
|---|---|
| **日期顯示** | 自動取得今日日期，以 `YYYY . MM . DD / 星期` 的點分格式呈現 |
| **每日禪語** | 從 17 句精選中英對照文青語錄中隨機選取，每次開啟皆不同 |
| **SYNC 同步按鈕** | 一鍵授權登入 Google，同步 Google Calendar 與 Google Tasks |
| **暗／亮色模式切換** | 點擊右上角圓形圖示，在暖米紙質亮色模式與深夜沉靜暗色模式之間切換 |

---

### 📋 左側：手頭的事（Tasks 待辦任務）

> *「萬事起於當下一刻。」*

- **Google Tasks 完整串接**：登入後自動從您的 Google Tasks 抓取全部任務清單（TaskLists）與任務。
- **自動三分類**：根據到期日自動分類為：
  - 🔴 **逾期未完（OVERDUE）**：已超過到期日的任務，摺疊收起，帶警示圖示。
  - ⭐ **今日待辦（TODAY）**：今天到期或無期限的任務，預設展開。
  - 📦 **待處理備忘（BACKLOG）**：未來日期的任務，摺疊收起。
- **區段可摺疊**：每個分類區段標題可以點擊展開或收合。
- **一鍵完成**：點擊任務左側的核取框，同步標記 Google Tasks 中的任務為已完成，並伴有條紋刪除線動畫。
- **快速新增任務**：底部輸入框可直接新增任務至 Google Tasks 的預設清單，按 `Enter` 或點擊 `+` 送出。
- **連結跳轉**：點擊任務文字，可直接跳轉到 Google Tasks 網頁對應的任務。
- **未授權時本機模式**：未登入 Google 時，任務資料自動改為讀寫本機 `localStorage`，不影響日常使用。

---

### 📅 右側：今日歷歷（Calendar 今日時間軸）

> *「在時間的河流裡，寫下今天生活過的痕跡。」*

- **Google Calendar 完整串接**：登入後自動讀取您所有訂閱的 Google 日曆，並只呈現今天的行程。
- **全天摘要區（All-Day Highlights）**：全天性質的行程（節日、假日、全天任務）以置頂的摘要卡片呈現，不擠入時間軸。
- **視覺化時間軸**：有特定時間的行程，依照時間先後以左右交錯的卡片佈局呈現在時間脊線兩側。
- **現在時間指示線**：在時間軸上以虛線標記當下所在的時刻，並隨分鐘自動更新位置。
- **行程詳細彈窗**：點擊任一行程卡片，會彈出優雅的全屏遮罩模態視窗，顯示行程標題、所屬日曆、完整時間與地點。
- **空狀態禪意畫面**：當今天沒有任何行程時，隱藏時間脊線，以「今天，時光無痕 / A Day in Quietude」的美學卡片呈現，附帶暖色太陽圖示與詩意文案。
- **未授權時範例模式**：未登入 Google 時，自動展示三筆範例行程，引導使用者體驗介面。

## ⚙️ 技術架構

```
minimal-dashboard/
├── index.html              # 主頁面結構
├── style.css               # 全域設計系統（CSS 變數、動畫、元件樣式）
├── app.js                  # 應用程式邏輯（狀態管理、API 呼叫、渲染）
├── README.md               # 本文件
└── GOOGLE_API_INTEGRATION.md  # Google API 串接備忘錄與實作指南
```

| 技術 | 說明 |
|---|---|
| **純前端（Vanilla）** | 無任何框架依賴，HTML + CSS + JavaScript |
| **Google Identity Services** | OAuth 2.0 隱式授權流程，純瀏覽器端登入 |
| **Google Calendar API v3** | 讀取使用者所有日曆的今日行程 |
| **Google Tasks API v1** | 讀取與完成使用者的 Google Tasks 任務 |
| **localStorage** | 本機模式下任務的持久化儲存 |
| **sessionStorage** | Google Access Token 的分頁層級儲存 |

## 🚀 使用方式

### 方式 A：本機直接開啟
1. 下載或 Clone 本專案資料夾至本機。
2. 直接雙擊 `index.html`，用 Chrome / Edge / Safari 等現代瀏覽器開啟即可使用。
3. 點擊右上角的 `SYNC` 按鈕，登入授權您的 Google 帳號，即可同步您的 Google 行程與待辦任務。

### 方式 B：部署至 GitHub Pages
1. 在 GitHub 建立一個**公開（Public）**的新專案庫。
2. 將本資料夾內所有檔案拖曳上傳至專案庫。
3. 前往 `Settings > Pages`，將 Branch 設定為 `main`，點擊 `Save`。
4. 稍候 1~2 分鐘，即可透過 `https://您的帳號.github.io/minimal-dashboard/` 隨時隨地存取。
5. **重要**：上線前請至 [Google Cloud Console](https://console.cloud.google.com/) 的 OAuth 憑證設定中，新增您的 GitHub Pages 網址為授權來源，Google 登入功能才能正常運作。

## 🔐 隱私說明

- **資料零外洩**：本網頁不含任何後端伺服器，所有資料皆存於您**自己的瀏覽器本機**（localStorage / sessionStorage），與任何第三方伺服器完全無關。
- **公開網址不代表資料公開**：即使您部署在 GitHub Pages 公開網址，其他人打開網頁只會看到空白狀態，**絕對無法**存取您的 Google 帳號資料。
- **Token 一小時自動失效**：Google 的 Access Token 有效期限為 60 分鐘。過期後，網頁會**自動清除過期憑證**，並將同步按鈕恢復為待授權狀態，您只需重新點擊 `SYNC` 即可快速恢復同步，而不會卡死在錯誤狀態。

## 🗺️ 未來功能路線圖（Roadmap）

以下是社群研究後整理出、最適合融入 Kontext 質感美學的追加功能候選清單，依照可行性與優先程度排列。

### ⭕ 優先考慮加入

#### 🍅 1. 極簡番茄鐘與白噪音（Zen Timer & Ambience）
- 在「手頭的事」下方嵌入一個極細線條的倒數番茄鐘（預設 25 分鐘 / 5 分鐘休息）。
- 點擊啟動時，可選擇伴隨環境音效（如：`🌧️ 雨聲`、`🔥 柴火`、`☕ 咖啡館`）。
- 計時進行中背景有極淡的呼吸燈律動，強化進入心流的儀式感。
- 完成一個番茄後顯示輕柔的完成提示，並記錄今日累計的專注時數。

#### 📝 2. 今日小記 / 閃念膠囊（Daily Scratchpad）
- 在頁面某處提供一個極簡的隨手文字草稿區，像書桌上的便條紙。
- 支援 Markdown 基本語法（粗體、斜體、清單）的簡易解析。
- 每天的草稿**自動存入 localStorage**，關閉後重開依然保留。
- 可選擇「清除今日小記」或「封存至過去記錄」。

### 🔵 中期考慮加入

#### ⛅ 3. 今日氣象（Ambient Weather）
- 在頁首日期旁以極細文字呈現當地氣溫與天氣圖示（如：`24°C ☁️`）。
- 串接 Open-Meteo（免費，無需 API Key）或 OpenWeatherMap API 取得天氣資料。
- 氣象圖示依天氣狀況（晴天 / 多雲 / 雨天 / 雷陣雨）呈現對應的 SVG 動態微動畫。

#### 📊 4. 習慣追蹤 / 專注足跡（Habit Tracker）
- 在頁面底端加上一排可自訂的極簡習慣打卡圓點（如：`閱讀`、`喝水`、`運動`、`早起`）。
- 每日按下圓點即打卡，以週為單位呈現完成率的熱力圖（Heatmap）。
- 完成的 Tasks 數量也會貢獻到今日的「專注足跡」指數。

### 🟡 長期探索

#### 🌅 5. 晨間與晚間儀式（Morning & Evening Rituals）
- 點擊頁面角落的特定圖示，展開溫柔的引導彈窗。
- **晨間模式**（開啟網頁時自動觸發）：引導您寫下「今天最想完成的三件事」。
- **晚間模式**（設定時間點後觸發）：引導您記錄「今天值得感謝的一件事」與「明日最重要的準備」。
- 所有填寫內容存入 localStorage，可於「日記回顧」頁籤中翻閱歷史紀錄。

#### 🔐 6. 網頁密碼鎖（Personal Access Lock）
- 在網頁入口加上一個 Kontext 風格的極簡密碼輸入畫面，防止不知情者直接存取。
- 密碼以雜湊值（SHA-256）儲存於代碼中，具備基本的防止直接查看機制。
- 驗證成功後，本機瀏覽器記住授權狀態，後續瀏覽不需要再次輸入密碼。

#### 📖 7. 日記回顧 / 時光痕跡（Memory Lane）
- 記錄每天的「今日歷歷」快照，讓使用者可以翻閱過去幾週的行程與任務完成記錄。
- 以月曆格子呈現過去每日的完成任務數量，點擊某天可以回看當天的完整記錄。
- 配合晨晚間儀式的文字記錄，讓儀表板進化為一本「無形的日記本」。
